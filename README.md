# Lab 8: Binary Tree Implementation

A Java data structures lab that implements a binary tree with separate node, tree, and runner classes.

## Highlights
Implements BTNode.
Implements BinaryTree.
Uses Lab8_Runner as the entry point.
Separates tree structure from demonstration code.

## Overview
Lab 8 introduces binary tree structure in Java. The node class stores tree data, the tree class manages behavior, and the runner demonstrates the implementation.
The project is organized as a small multi-class data structures assignment.

## Why This Project
Trees are a major topic in data structures. This lab provides hands-on practice with how tree nodes connect and how tree operations can be organized in Java.

## Usage
Compile: Compile all Java files with javac *.java.
Run: Execute with java Lab8_Runner.
Review BinaryTree.java and BTNode.java to understand the implementation.

## Installation
Ensure you have the Java Development Kit (JDK) installed on your system.
Open a terminal in the lab folder before compiling so the program can find any required local text files.

## Architecture
File Structure: The project contains BTNode.java, BinaryTree.java, and Lab8_Runner.java.
Components: BTNode.java defines nodes, BinaryTree.java manages tree operations, and Lab8_Runner.java demonstrates usage.
